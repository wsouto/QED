# Methodology

## Core Principle

@raicher's analysis is built on **technical analysis** of Bitcoin's price chart using **RSI (Relative Strength Index)**, **moving averages**, and **cycle theory**. The core insight: Bitcoin moves in identifiable macro cycles that repeat with predictable patterns.

## The 7-Year Cycle Theory

Introduced in the [[01-First-Post]] thread. Bitcoin's price action follows approximately 7-year cycles, divided into distinct phases marked by colored arrows:

| Arrow | Phase | Description |
|---|---|---|
| 🟡 Yellow | Start | RSI dips below 43.83 — cycle bottom forms |
| 🟠 Orange | 1st impulse | First bullish move after the bottom |
| 🔵 Blue | 2nd impulse | Main parabolic leg begins |
| 🔴 Red | Top | Cycle top — RSI above 71.52 |
| 🟢 Green | Bear market start | Bull market ends, accumulation begins |

The RSI levels are critical:
- **RSI 71.52** → Top confirmation
- **RSI 43.82** → Bottom confirmation (buy zone)

## RSI Crossover Strategy

The most frequently cited entry signal (see [[04-Glossary#QED]] for his confirmation marker).

**Rule:** When the **weekly RSI crosses above its moving average**, it produces a buy signal. Historically:
- **100% win rate** — every crossover produced a profitable trade
- Average return: ~202%
- Best: 2,300% (Nov 2012)
- Worst: 14% (Apr 2016)
- 31st crossover occurred in September 2024

## Key Indicators Used

| Indicator | Purpose |
|---|---|
| **RSI** | Momentum oscillator — primary signal generator |
| **StochRSI** | RSI of RSI — finer timing for entries/exits |
| **MA7, MA21, MA77** | Short/medium/long moving averages |
| **EMA231** | Very long-term trend filter (~1 year) |
| **BBW** (Bollinger Band Width) | Volatility contraction → expansion signals |
| **Below-Below-Below** | Multi-timeframe RSI confirmation (see [[03-Raicher-Strategy]]) |

## Colored Arrow System

His charts use a consistent color-coding system that makes the analysis scannable at a glance. Each arrow represents a structural inflection point. The system evolved from the 7-year cycle theory and became more granular over time.

## Key RSI Levels

- **Below 30**: Oversold — accumulation zone
- **30-50**: Bearish momentum
- **50**: Midline — bullish/bearish divide
- **50-70**: Bullish momentum
- **Above 70**: Overbought — can stay overbought in trends
- **71.52**: His specific top confirmation level
- **43.83**: His specific bottom confirmation level

## Timeframe Hierarchy

He analyzes multiple timeframes and uses confluences across them:
1. **Monthly** — macro cycle phase, RSI on monthly
2. **Weekly** — primary trend, RSI crossover signals
3. **Daily** — short-term analysis, entries/exits
4. **4H / 1H** — intraday timing (less common)
